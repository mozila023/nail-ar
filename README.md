# ลองเล็บ AR

เว็บลองเล็บที่จับตำแหน่งเล็บจากภาพมือจริงด้วย MediaPipe Hand Landmarker รองรับทั้งรูปถ่ายและกล้องสด เลือกสี ลาย และส่วนเสริมแล้วเห็นผลทันที พร้อมคำนวณราคา

ทั้งหมดอยู่ในไฟล์ `index.html` ไฟล์เดียว ไม่ต้องติดตั้งหรือ build

## เอาขึ้นเว็บด้วย GitHub + Vercel

1. สมัครหรือเข้าสู่ระบบ https://github.com แล้วกด **New repository** ตั้งชื่อ เช่น `nail-ar` เลือก Public แล้วกด Create
2. ในหน้า repository กด **Add file → Upload files** ลากไฟล์ `index.html` (และ README.md) ลงไป แล้วกด **Commit changes**
3. ไปที่ https://vercel.com กด **Sign up / Log in with GitHub**
4. กด **Add New → Project** เลือก repository `nail-ar` แล้วกด **Import**
5. ช่อง Framework Preset เลือก **Other** แล้วกด **Deploy**
6. รอประมาณหนึ่งนาที จะได้ลิงก์ เช่น `https://nail-ar.vercel.app` เปิดบนมือถือแล้วอนุญาตการใช้กล้อง

ทุกครั้งที่แก้ `index.html` บน GitHub แล้ว commit Vercel จะอัปเดตเว็บให้อัตโนมัติ

## ทดสอบบนเครื่องตัวเอง

กล้องใช้ได้เฉพาะเว็บที่เป็น https หรือ localhost เท่านั้น (เปิดไฟล์ตรง ๆ แบบ file:// ใช้ไม่ได้)

```
npx serve .
```

แล้วเปิด http://localhost:3000

## หมายเหตุ

- ครั้งแรกที่เปิด เว็บจะดาวน์โหลดโมเดลจับมือประมาณ 8 MB ครั้งต่อไปจะเร็วขึ้น
- ระบบรู้ตำแหน่งนิ้ว แต่ไม่ได้เห็นขอบเล็บจริง ถ้าเล็บเสมือนเหลื่อม ให้ปรับด้วยแถบ "ขนาดเล็บ" และ "ตำแหน่ง" หรือลากทีละนิ้วในโหมดรูปถ่าย
- แก้ราคาและรายการได้ที่ตัวแปร `SW` (สี), `ST` (ลาย), `AD` (ส่วนเสริม) และ `BASE` (ราคาเริ่มต้น) ใน `index.html`
